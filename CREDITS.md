## UI Vault library components

Both patterns are from [UI Vault](https://github.com/konethegreat/ui-vault), tier `library/`,
authored by Kone Tshivhinda and licensed MIT.

| Pattern | Source | What this site uses | Changes |
| --- | --- | --- | --- |
| Button | [library/button](https://github.com/konethegreat/ui-vault/tree/main/library/button) | Class names and CSS custom properties | Re-themed to paper, ink and cornflower; React wrapper not used |
| Nebula Hero | [library/nebula-hero](https://github.com/konethegreat/ui-vault/tree/main/library/nebula-hero) | WebGL2 shader, loop, reduced-motion and visibility handling | Ported from React to a plain module; warm palette replaced with cornflower and ink |

Nebula Hero's visual direction is inspired by [Star Nest by Pablo Roman Andrioli](https://www.shadertoy.com/view/XlfGRj)
and the shader adaptation credited to Matthias Hurrle (@atzedent). No shader code was copied from
either; the shader here is the original clean-room implementation from the UI Vault.
