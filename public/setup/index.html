Setup guide

From download to your first goal.

Seven short steps for your computer. No terminal needed on Windows or macOS: the app installs its own tools and you only answer the prompts a person has to answer. Tick each step as you go.

01

Download the app

1 minute

Windows

Press the button. Your browser saves AgentOS.Studio_1.2.6_x64-setup.exe, about 6 MB, to your Downloads folder.

Download for Windows

Working for a company that installs software centrally? Your IT team may prefer the MSI installer.

macOS

Not sure which Mac you have? Open the Apple menu, then About This Mac. If it says Chip: Apple M1 (or M2, M3, M4), pick Apple Silicon. If it says Processor: Intel, pick Intel.

Download for Apple Silicon Download for Intel

Linux

The AppImage runs on almost every distribution. If you use Ubuntu or Debian, the .deb installs like any other package; on Fedora, use the .rpm.

Download the AppImage .deb .rpm

Optional: check that the file is the one we published

Each release on GitHub lists a SHA256SUMS file per system. Run the command for your system in the folder with the download, and compare the long string it prints with the line for the same file name. They must match exactly; if they do not, delete the file and download it again.

Windows, in PowerShell:

Get-FileHash .\AgentOS.Studio_1.2.6_x64-setup.exe -Algorithm SHA256

macOS and Linux, in Terminal:

shasum -a 256 ~/Downloads/AgentOS.Studio_1.2.6_*
02

Run the installer

2 minutes

Windows

  1. Open your Downloads folder and double-click AgentOS.Studio_1.2.6_x64-setup.exe.
  2. A blue box appears: Windows protected your PC. This is expected: the app is new and not signed with a paid certificate. Click More info.
  3. The box now shows the app name and Unknown publisher. Click Run anyway.
  4. The installer opens. Click Next and Install. It installs for your user only and does not need an administrator password.

No More info link at all? Then Smart App Control or a work policy is blocking it, not SmartScreen. See Troubleshooting. Do not switch off Windows security to get past it.

macOS

  1. Double-click the downloaded .dmg. A window opens with the AgentOS Studio icon.
  2. Drag the icon onto the Applications folder in that window.
  3. Open Applications in Finder. Right-click (or Control-click) AgentOS Studio and choose Open.
  4. macOS says it could not verify the app. Click Open in that box. From now on it opens normally.

Only seeing Move to Trash and Done? Click Done, open System Settings, then Privacy and Security, scroll down and click Open Anyway. Apple explains this at support.apple.com/en-us/102445.

Linux

AppImage: open Terminal in your Downloads folder and run these two lines. The first makes the file runnable, the second starts it.

chmod +x AgentOS.Studio_1.2.6_amd64.AppImage
./AgentOS.Studio_1.2.6_amd64.AppImage

.deb (Ubuntu, Debian, Mint):

sudo apt install ./AgentOS.Studio_1.2.6_amd64.deb

.rpm (Fedora, RHEL):

sudo dnf install ./AgentOS.Studio-1.2.6-1.x86_64.rpm

If the AppImage says FUSE is missing, install it with sudo apt install libfuse2 (Ubuntu 22.04) or sudo apt install libfuse2t64 (Ubuntu 24.04), then run it again.

03

Open it for the first time

1 minute, hands off

Open AgentOS Studio: from the Start menu on Windows, from Applications on macOS, or from your app menu on Linux. The first launch takes a few seconds longer because the app gets itself ready. You do not need to do anything during this:

  • It creates its own folders and database.
  • It creates a notes folder called AgentOS Vault in your Documents. This is the shared memory every agent reads. You can open it in Obsidian later, but you do not have to.
  • It runs nine quick health checks and shows them on the start screen.

A short welcome tour then offers three stops: Setup, Missions and Help. Take the first one, Setup. You can also reach it any time from the left rail: System, then Setup.

04

Let Setup install the rest

5 to 10 minutes, mostly waiting

The Setup screen checks your computer and lists every tool AgentOS Studio works with: Git, Node.js, the GitHub command line, Claude Code, Hermes and its plugins, your vault and the connections between agents. Green means ready. Amber means missing or broken. Rows marked optional are for tools you do not have to use.

One button: Set up everything

A Set up everything button sits at the top of the Setup screen. It shows the plan first, then installs every missing tool in one pass:

Windows

Windows: you answer one admin prompt (the box that asks Do you want to allow this app to make changes to your device?, click Yes). That single prompt covers Git, Node.js, the GitHub CLI and Claude Code, installed with winget. If winget itself is missing, the same pass installs it first.

macOS

macOS: the tools are installed with Homebrew. If Homebrew is missing, its official installer opens in Terminal and asks for your Mac password once; type it (nothing shows while you type) and press Return.

Linux

Linux: one password prompt (pkexec) installs the missing tools with apt or dnf, whichever your system uses.

After the tools, with no further prompts, Studio:

  1. installs Hermes and its plugins,
  2. fixes your PATH so new tools are found without a restart,
  3. creates the Obsidian vault if you do not have one,
  4. connects the AgentOS hub to every agent, and to Claude Desktop, Cursor, VS Code, Windsurf and Codex when they are installed,
  5. and finally opens the sign-ins in step 5.

On an older 1.0 build

Version 1.0 does the same work one row at a time. Each amber row has its own button: Install, Sign in or Change model. The big button at the top, Auto-Setup and Repair Everything, repairs everything that is broken in one go (1.1 renames it Repair what is broken). Press it, watch the Setup log, then press Re-check.

Windows

Windows with 1.0: each tool installs through winget and may show its own admin prompt; click Yes each time. If a row says winget is not available, open the Microsoft Store, install App Installer, and press the button again.

macOS

macOS with 1.0: Studio installs tools with Homebrew, so install Homebrew first. Open Terminal (press Command and Space, type Terminal, press Return), paste this line, press Return and follow what it says:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Then go back to Setup and press Auto-Setup and Repair Everything.

Linux

Linux with 1.0: Studio asks you to install the system tools yourself. Paste the line for your system into Terminal, then press Re-check in Setup.

Ubuntu, Debian and Mint:

sudo apt install -y git nodejs npm gh

Fedora:

sudo dnf install -y git nodejs gh

Claude Code, from Anthropic's official installer:

curl -fsSL https://claude.ai/install.sh | bash

Studio then installs Hermes, its plugins and the vault itself when you press Auto-Setup and Repair Everything.

A row stays amber after an install? Close AgentOS Studio, open it again and press Re-check. New tools are sometimes only visible to programs started after the install.

05

Sign in to your accounts

3 minutes

Some things only you can do, because they are your accounts. Studio opens each one for you; you sign in and approve. You need at least one way to reach a model: a Claude subscription, or an API key.

1. GitHub
  1. In Setup, press Sign in on the GitHub row.
  2. A one-time code appears in the Setup log and github.com opens. Copy the code into the page.
  3. Click Authorize. No GitHub account yet? Create one free at github.com/signup.
2. Claude
  1. Press Sign in on the Claude row.
  2. claude.ai opens in your browser. Sign in with your Claude Pro or Max account.
  3. Click Authorize, then come back to Studio and press Re-check.
3. Hermes model
  1. Press Change model on the Hermes model row.
  2. Pick a provider you have signed in to or have a key for, then a model from its list.
  3. Not sure? Choose the Claude subscription if you have one; otherwise OpenRouter.
4. An API key, such as OpenRouter
  1. Go to openrouter.ai/keys, sign in, and press Create key. Add a few dollars of credit.
  2. Copy the key. In Setup, find Connect your subscriptions, paste it into the OpenRouter field, press Save key.
  3. Studio stores it in Hermes' own settings and only ever shows its name again.

A Claude subscription is a flat monthly price. OpenRouter charges per use, so Studio shows your OpenRouter spend and lets each goal have a budget.

06

Your first chat and first goal

5 minutes

Your first chat

  1. Click Chat in the left rail.
  2. Choose a folder to work in, for example a project you already have. The agent can read the files in it.
  3. Pick Hermes or Claude Code at the top, type a question such as What is in this folder, and what would you improve first?, and press Enter.

The answer streams in. Every action the agent takes, such as reading a file or running a command, appears as a card you can open. If it wants to do something risky, Studio asks you first.

Your first goal

  1. Click Work, then Goals, then New goal.
  2. Write the outcome in one sentence, for example Add a dark mode switch to the settings page.
  3. Pick the repository. Press Add check and say how Studio will know it is done: a command such as npm test, a web address that must load, or a file that must exist.
  4. Leave the level on Ask on risk, so Studio asks you before anything risky. Press Create goal.

Hermes splits the goal into missions, agents work on them in separate copies of the code, a second agent reviews every change, and the checks run at the end. Follow it live in Work, then Run timeline.

07

If something goes wrong

when you need it

Windows shows no More info link, or says Smart App Control blocked it

That is Smart App Control or an organisation policy, not SmartScreen, and it has no per-app override. Check it in Windows Security, App and browser control, Smart App Control. If it is On, install on a computer where it is Off or build from source. Switching it off cannot be undone without reinstalling Windows, so we do not recommend it just for one app. Details: install notes.

macOS says the app is damaged or cannot be opened

Delete the copy in Applications, download the DMG again, drag it into Applications, and use right-click, Open. If only Move to Trash appears, use Open Anyway in System Settings, Privacy and Security.

The Linux AppImage does nothing when I double-click it

Run chmod +x on it as shown in step 2, then start it from Terminal to see any message. A FUSE error means installing libfuse2; you can also start it with --appimage-extract-and-run.

A tool is installed but Setup still shows it as missing

Close AgentOS Studio completely and open it again, then press Re-check. If it is still missing, sign out of your computer and back in: some installers only update the search path for new sessions. Set up everything fixes the path for you.

The sign-in window never opened

Look at the Setup log at the bottom of the Setup screen: it prints the web address and any one-time code. Copy the address into your browser by hand. Then press Re-check.

Chat answers with an error about the model or the key

Open Setup and check the Hermes model row. Pick a model from a provider that is connected, or save a fresh OpenRouter key. A key with no credit fails too; add credit at openrouter.ai.

Something else is red

Open System, then Diagnostics. It runs the start-up checks again, shows each result and offers a fix button where one exists. The full guide is in Troubleshooting.

I need a person

Open an issue at github.com/konethegreat/agentos-studio/issues with what you clicked, what you expected and a screenshot. Diagnostics can copy the logs for you; check them for anything private before you paste.

That is everything.
