Who made this, and what it borrows.

This site is original work except for two patterns from the UI Vault library and the fonts. Both are credited here and in the page footer.

Authorship

Designed and built by Kone Tshivhinda for K-ONE IT SOLUTIONS, Johannesburg, South Africa. AgentOS Studio itself is MIT licensed and lives at github.com/konethegreat/agentos-studio.

UI Vault library components

Two patterns come from the UI Vault, a provenance-first reference library. Its library/ tier is original work by Kone Tshivhinda under the MIT license, which allows reuse with attribution.

Button by Kone Tshivhinda, MIT. Source: library/button.

The CSS custom properties and class names are reused, with the palette re-themed to paper, ink and cornflower. The React wrapper is not used here because this site has no React runtime.

Nebula Hero by Kone Tshivhinda, MIT. Source: library/nebula-hero.

The WebGL2 shader and its loop are ported from the React component to a plain module, with the warm palette replaced by cornflower and ink. Reduced motion still renders a single static frame, and the loop still pauses offscreen. Visual direction is inspired by Star Nest by Pablo Roman Andrioli and the shader adaptation credited to Matthias Hurrle (@atzedent); no shader code was copied from either.

Fonts

Instrument Serif, Geist and Geist Mono are self-hosted from this domain and licensed under the SIL Open Font License 1.1. The full license text ships at /fonts/OFL.txt.

What is not here

No component from the UI Vault's references/ tier is copied into this site. That tier includes work with other licenses and authors, and it stays in the vault as documentation. If a reference is added later, its author and license will be named here before the code is published.
