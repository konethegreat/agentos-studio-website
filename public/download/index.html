Before you click Run

The builds are not signed with a paid certificate. On Windows, the setup opens Windows protected your PC. Click More info, then Run anyway. On macOS, right-click the app and choose Open, or use Open Anyway under Privacy and Security.

The install notes cover Smart App Control, what to do when it blocks the file, and why we do not recommend turning a security feature off. Read install notes

Check the file

When a release includes per-platform SHA256SUMS files, compare the hash before you run the installer. The install notes give the exact PowerShell, shasum and sha256sum commands.

Open the release page

What it needs

Windows: 10 or 11, x64. Edge WebView2 ships with Windows; the installer fetches it if it is missing.
macOS: 11 or later, Apple Silicon or Intel.
Linux: x64 with WebKitGTK 4.1 and GTK 3. FUSE 2 for the AppImage.

First run

Open Setup and press Auto-Setup and Repair Everything (in 1.1, Set up everything). Studio installs what is missing and opens sign-in windows where one is needed. A machine with only Hermes is a supported setup; the other agents and Notion are optional rows.
