Privacy

This site keeps it small.

This page covers this website. The app has its own privacy page, which lists the files it reads and the network requests it makes.

No cookies No analytics No third-party scripts

What this site does

The pages are static HTML, CSS and two small scripts served by Cloudflare. Fonts are served from this domain. There is no account, no form, no newsletter and no advertising.

  • No cookies are set, and nothing is stored in your browser.
  • No analytics, pixel, session recorder or tag manager runs here.
  • No third-party script or font host receives a request from this site.

What Cloudflare sees

Cloudflare processes each request to deliver the page and to protect the site from abuse. That includes the request URL, your IP address, your user agent and the time. This is ordinary web server processing, not a profile built by this site. Cloudflare's own privacy terms apply to its logs.

This site does not combine those logs with anything else, and it has no place to store personal data even if it wanted to.

Downloads

When you choose a platform, this site's Worker asks the public GitHub API for the latest AgentOS Studio release, then redirects your browser to the installer on GitHub. GitHub sees the download request and its own privacy policy applies from that point. The Worker does not record who downloaded what.

The release lookup is cached at the edge for a short time, and a copy of the last known release is stored in this repository, so the download page keeps working when GitHub is unreachable.

The app itself

AgentOS Studio stores chats, settings and memory on your machine. It has no telemetry. The app privacy page lists every file it reads and every network request it makes, including update checks and model provider traffic.
