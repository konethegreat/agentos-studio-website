What it does

Chat, goals and memory in one window.

No terminals to wire together and no prompts to copy between tools. The agents keep their own accounts and models; Studio gives them a shared desk and a way to finish work.

How work gets done

A goal ends in a reviewed merge, not a transcript.

Say what done means.

One sentence for the outcome, plus a check: a command, a web address or a file that must exist.

Hermes plans it.

The goal becomes missions, each with a repository, criteria and a budget.

Agents work apart.

Every mission runs in its own copy of the code, so your folder stays yours.

A second agent reviews.

Approved work merges as one commit; then the checks run on the result.

Show steps for

Windows

Windows 10 and 11

AgentOS Studio for Windows

Version 1.2.7. Free, MIT licensed, no account needed.

Download for Windows
  • Setup, per user (pick this one)
  • MSI, for managed installs
  1. 01Download the setup file. It is about 6 MB.
  2. 02Open it. Windows shows a blue Windows protected your PC box: click More info, then Run anyway.
  3. 03Open AgentOS Studio from the Start menu and go to Setup.

macOS

macOS 11 and later

AgentOS Studio for macOS

Version 1.2.7. Free, MIT licensed, no account needed.

Download for macOS
  • Apple Silicon (M1 and later)
  • Intel Macs
  1. 01Download the DMG. Most Macs from 2020 on are Apple Silicon; Intel is in the list.
  2. 02Drag AgentOS Studio into Applications.
  3. 03Right-click the app, choose Open, then Open again. macOS asks only the first time.

Linux

Linux, x64

AgentOS Studio for Linux

Version 1.2.7. Free, MIT licensed, no account needed.

Download for Linux
  • AppImage, runs anywhere
  • .deb, Debian and Ubuntu
  • .rpm, Fedora and RHEL
  1. 01Download the AppImage, or the .deb or .rpm for your system.
  2. 02Make it runnable: chmod +x AgentOS.Studio_*.AppImage.
  3. 03Run it and open Setup. One password prompt installs what is missing.

Builds are not signed with a paid certificate, so Windows and macOS ask once on the first launch. The setup guide shows the exact boxes and what to click. Nothing asks you to switch off a security setting.

From download to first goal

Six steps, about fifteen minutes.

Never used a terminal? You will not need one on Windows or macOS. The app installs its own tools; you answer the prompts only a person can answer.

  1. 01DownloadPick your system. The site picks the right file.
  2. 02InstallWhat to click when Windows or macOS asks.
  3. 03First launchWhat the app does on its own the first time.
  4. 04Setup screenOne button installs every missing tool.
  5. 05Sign inGitHub, Claude, a model and one API key.
  6. 06First chat and goalAsk something, then hand over real work.
In every release since 1.1

One button sets up everything. The Setup screen has a Set up everything button: one admin prompt installs every missing tool, then Studio installs Hermes, creates your vault, connects every agent and editor it finds, and opens the sign-ins.

The setup guide walks through it, and the docs cover everything after.

Ready when you are.

Bring one agent or four. Studio connects what is installed and leaves the rest optional.
