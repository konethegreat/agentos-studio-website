01 / SURFACES

Chat, missions and memory in the same window.

No terminals to wire together and no prompts to copy between tools. The agents you already use keep their own accounts and their own models; Studio gives them a shared desk.

Chat

Talk to the agent you already pay for.

Open a folder, pick Hermes, Claude Code, Qoder or Antigravity, and talk. Replies stream in with rendered Markdown, and every tool call appears as a card you can open.

Missions

Give work a definition of done.

Point an agent at a repository, state the goal and the acceptance criteria. Studio creates an isolated worktree, runs the mission and keeps the diff for review.

Memory

Your notes, in a folder you own.

Every agent reads the same vault of Markdown files. Recall is ranked, decisions get recorded, and nothing is hidden in a store you cannot open.

02 / MISSIONS

A mission ends in a reviewed merge, not a transcript.

The difference between a useful agent and a fleet is what happens after the code is written. Studio makes the end of a mission a decision, not a summary.

01

The goal becomes a definition of done.

The mission records what finished means: the repository, the criteria, the checks. The agent plans against that, not against a chat message.

02

Work happens in an isolated worktree.

Each mission gets its own copy of the repository, so two agents cannot step on each other and your working tree stays yours.

03

A second agent reviews the diff.

The reviewer opens the pull request, reads the change and either approves it or sends it back with findings. The agent that wrote the code does not grade its own work.

04

The merge is squashed and checked.

Approved work lands as one commit with the evidence attached. Checks run before the merge, and the result is recorded on the mission.

Review gate lives in the app, not in a prompt.

03 / PLATFORM

Built local-first, in Rust.

One native binary is the desktop app and the shared MCP bus. Your chats, keys and notes stay on your machine unless you connect a service yourself.

04 / INSTALL

Install it honestly.

Builds are not signed with a paid certificate, so Windows SmartScreen and macOS Gatekeeper ask once. The install notes show the exact dialog and what to click. Nothing asks you to weaken a security setting.
